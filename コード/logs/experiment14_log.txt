   ★ 主要結果: CIRC と DELAY は Phase-1 の**スカラー統計量から識別不能**。
     真の回転（位相が +pi/2 で一定）でも受動遅延（位相が 2*pi*f*Delta で
     f に線形）でも、帯域積分 I_01 = ∫Im[S_01]df は非ゼロになり、
     判定ルール（閾値を超えるか）も「発火」になる。
     I_01 はスカラーであり、「位相が一定か f に線形か」を符号化しない。
     → 同一の I_01 値を、CIRC からも DELAY からも生成できる。
     → したがって閾値ベースの二分判定は循環/遅延を**原理的に**判別できない。
     → 判別には Phase-2（外部利得への応答の有無）が必要。
     （INDEP 腕の閾値比 0.79 は 1 近傍＝null と整合）

   注意（CIRC の減衰が DELAY より遅い理由）:
     CIRC は x,y が**同一の theta** の関数なので位相拡散が両者に同時に働き、
     y = tan(pi/2) x という瞬時関係が厳密に保存される。
     DELAY は x(t) と x(t-Delta) の**記憶**を要求するため、
     拡散が Delta 間に及べば崩壊する。
     → この差は 2 腕の**構成上の帰結**であり、実際の受動系が循環より
       必ず脆弱であることを意味しない。検出が成功する領域（低 D_theta）では
       両腕とも 1.00 で、判定は同一になる。

   注意（巻き数精度も位相拡散で低下する）:
     PC-1 の 0.01% は D_theta=0 の条件。PC-3 の D_theta>0 では
     巻き数誤差も 1.5%(D=50) → 25-55%(D=100) と増大し、
     検出率が 0.83 → 0.00 に落ちる領域と一致する。
     精度と検出力は整合しており、両方が位相 coherence に支配される。
     （DELAY 腕の巻き数が 100% 超ずれるのは、位相が decorrelate すると
      偏角が原点まわりを一周しない定義上の帰結）

結論（#7 正の対照）
====================================================================================================
1. **正の対照は成立する。** 巻き数が既知の Stuart–Landau 回転系で、
   実測巻き数は注入値へ相対誤差 <0.01% で回復し、FWER 制御下の
   ROI 判定は全シードで発火する。本論文の陰性結果は
   「推定器・プロトコルの無力」ではなく「**系に縮退がないため**」である。
2. **Phase-1 のスカラー統計量は循環と遅延を識別できない。**
   帯域積分 I_01 = ∫Im[S_01]df は「位相が一定（循環）」でも
   「位相が f に線形（遅延）」でも非ゼロになり、判定も共に発火する。
   PC-3b で両腕の I_01 値域が重なることを定量的に確認した。
   → Phase-2（介入応答）の存在が設計上必須であることの実証。
3. 検出力曲線は位相拡散 D_theta に依存して 1.00→0.00 へ遷移し、
   注入した循環が埋没すると検出が落ちる＝プロトコルの検出力は十分。
   （振幅ノイズではなく位相拡散で遷移する。振幅ノイズは theta を乱さない。）
4. 生産設定 nperseg=256 ではピーク周波数を回復できない（分解能制約）。
5. 狭帯域チャネルに対して iid 白色 null は反保守的（INDEP で 6/6 発火）。
   整合 null（INDEP アンサンブル）では名目値近傍に落ち着く。
   → 論文の FWER 制御に整合 null を使うべきことの追加的な示唆。
